# Kestra LanceDB Plugin

## Why

- **Serverless & Embedded**: LanceDB is an open-source, serverless vector database built on Apache Arrow and the Lance columnar format. It lets RAG and multimodal AI workflows persist vector indices on local disk or cloud object storage (S3, GCS, Azure) without managing a separate vector server.
- **Workflow Native**: Ingest embeddings generated by upstream tasks directly into LanceDB tables and perform low-latency similarity search with SQL metadata filtering.
- **Cost & Operational Efficiency**: Reduces AI infrastructure complexity and hosting costs by eliminating dedicated vector server instances.

## What

Provides components under `io.kestra.plugin.lancedb`:

- `TableCreate`: Initializes a vector table with vector dimension and distance metric (`COSINE`, `L2`, `DOT`).
- `Upsert`: Batch inserts or updates vector records and metadata from inline lists or `kestra://` storage files.
- `Search`: Performs approximate nearest neighbor (ANN) similarity search with optional SQL metadata filtering, returning matches inline (`FETCH`), as a single record (`FETCH_ONE`), or saving to internal storage (`STORE`).

## Tasks and Usage

### Example 1: Create a table

```yaml
id: lancedb_table_create
namespace: company.team

tasks:
  - id: create_table
    type: io.kestra.plugin.lancedb.TableCreate
    uri: "s3://my-bucket/lancedb"
    table: documents
    dimension: 1536
    distanceMetric: COSINE
    storageOptions:
      aws_region: "us-east-1"
      aws_access_key_id: "{{ secret('AWS_ACCESS_KEY_ID') }}"
      aws_secret_access_key: "{{ secret('AWS_SECRET_ACCESS_KEY') }}"
```

### Example 2: Upsert embeddings from an upstream task

```yaml
id: lancedb_upsert
namespace: company.team

tasks:
  - id: upsert
    type: io.kestra.plugin.lancedb.Upsert
    uri: "s3://my-bucket/lancedb"
    table: documents
    from: "{{ outputs.embed.uri }}"
    batchSize: 500
```

### Example 3: Similarity search with metadata filter

```yaml
id: lancedb_search
namespace: company.team

tasks:
  - id: search
    type: io.kestra.plugin.lancedb.Search
    uri: "s3://my-bucket/lancedb"
    table: documents
    vector: "{{ outputs.embed.vector }}"
    topK: 5
    filter: "category = 'docs'"
    fetchType: FETCH

  - id: log_results
    type: io.kestra.plugin.core.log.Log
    message: "Found {{ outputs.search.size }} matches"
```

## Running Kestra locally with this plugin

1. Build the shadow JAR: `./gradlew shadowJar`. The output lands in `build/libs/`.
2. Run `docker compose up`. `docker-compose.yml` mounts `build/libs/` to `/app/plugins/` so Kestra registers the plugin on startup.
3. Access Kestra UI at [localhost:8080](http://localhost:8080).
